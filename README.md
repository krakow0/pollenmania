# pollenmania
this is my first game using python. it's a game involving a bee who collects pollen to defend his hive from attackers.

controls are W,A,S,D (movement)
hold E to collect pollen
press Q to attack

I relied heavily on learning pygame through this website:
https://www.geeksforgeeks.org/python/python-for-game-development-getting-started-with-pygame/
So, special thanks to their helpful guidelines for beginners like me :P
